# Work Report — 2025-12-12

## Summary
- Улучшена механика WordCollaps: авто‑схлопывание колонок после удаления блоков, бомбовый бонус удаляет пары и сразу уплотняет поле, шкала заряда бомбы и увеличенная заморозка.
- Обновлён визуал плиток: повышена читаемость, контраст ролей, мягкие тени, бейджи бонусов.
- Подготовлена база для плавного ускорения спавна (отдельный интервал, связанный с настройкой скорости), далее можно ввести формулу ускорения.

## Details
- Добавлен `collapseBlocks`: после матча или бомбы колонки пересобираются и падают вниз без зазоров. Бомба теперь вызывает схлопывание сразу.
- Бонусы: бомба спавнится по шкале заряда (комбо ≥3 даёт +30%, иначе +10%), заморозка длится ~6 секунд. Бомба удаляет ~25% терминов (оба блока).
- Визуал блоков: шрифт 15px, скругление 12px, тени, текстовая подсветка, hover/active анимации; разные палитры для nor/tr, бейджи для бонусов, ускорено растворение matched.
- Спавн: введена переменная `spawnIntervalMs`, синхронизированная с выбором скорости. Можно добавить формулу ускорения, например каждые +1000 очков уменьшать интервал до минимума.
